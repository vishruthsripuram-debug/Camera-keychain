# Camera-keychain
Small camera keychain with multiple mounting points and easy micro sd storage

### Description
Tiny little camera keychain with storage for micro SD cards. Great to clip onto GoPro case or large camera strap mounting points. Carabiner mount on the side. Keychain and lanyard loop at the top, 'removable'. Cute little keychain to clip onto camera/camera bag for Micro SD storage.

### Build instructions
1. Print the parts. *
2. Take parts off of print bed carefully to avoid warping.
3. place lanyard loop in hot shoe socket.
4. Place lanyard within loop.
5. Attatch to whatever you like and use the door '**optional**'.

### Printing instructions
- Use 0.2 mm nozzle
- Use smallest layer height available
- Print with slow speeds <100 mm/s
- Print with highest quality setting
- Utilise extra cooling for overhang
